# Visible festive background correction

The previous atmosphere was too faint. This pass gives the header, hero and category section a visible champagne/gold gradient, including a continuous #F2E4C9 section junction and deeper antique-gold peripheral light. The existing shader opacity is reduced from .65 to .35 so its pale output cannot wash out the golden CSS foundation. Mobile uses the same gold tones around its stacked photograph.

No content, photography, geometry or functionality changed. Desktop and mobile preview checked with no horizontal overflow; desktop headline and category bounds match previous captures. Build and TypeScript pass with the supported webpack compiler. Screenshots: festive-desktop.png and festive-mobile.png. Exact photographic lighting from the reference is not claimed; its image is different from the site's preserved photograph. Functional flows and physical-device GPU profiling were not repeated.
